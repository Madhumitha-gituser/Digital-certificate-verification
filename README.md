# Digital Certificate Verification System
## VTU Information and Network Security (INS) — BIS 703

> **EDUCATIONAL DEMO — NOT AN OFFICIAL CERTIFICATE SYSTEM**

A complete digital certificate verification system demonstrating RSA-2048 digital signatures, SHA-256 hashing, and trusted database verification.

---

## 🚀 Quick Start (Windows PowerShell)

```powershell
# 1. Navigate to the project folder
cd "c:\Users\kaviy\Downloads\INS Proj\Digital-certificate-verification"

# 2. Install dependencies
pip install -r requirements.txt

# 3. Generate sample certificates (keys + DB + PDF + JSON files)
python generate_samples.py

# 4. Run the server
python app.py

# 5. Open your browser
# http://127.0.0.1:8000

# 6. Run tests
python -m pytest tests/ -v
```

## 🔐 Cryptography

- **Algorithm**: RSA-2048
- **Padding**: PSS (Probabilistic Signature Scheme)
- **Hash**: SHA-256
- **Key storage**: PEM files in `instance/` (outside public directories)

## 🗄️ Database

- **Engine**: SQLite (built into Python)
- **Location**: `instance/certificates.db`
- **Tables**: `certificates`, `admin_users`

## ⚠️ Security Notes

- The private key is NEVER exposed in HTML, PDFs, or API responses.
- All SQL queries use parameterized queries (no SQL injection).
- Session cookies are signed with a secret key.
- Input validation is performed server-side.
